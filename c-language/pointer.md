# 指针与内存

> 这是一份占位模板，把下面的内容替换成你自己的学习笔记即可。

## 1. 指针是什么

指针是一个变量，它存储的是另一个变量的**内存地址**。

```c
int a = 10;
int *p = &a;       // p 保存 a 的地址
printf("%d", *p);  // 解引用，输出 10
```

## 2. 关键概念

| 概念 | 说明 |
|---|---|
| `&` 取地址 | 取得变量的内存地址 |
| `*` 解引用 | 通过地址访问该地址上的值 |
| 指针类型 | 决定解引用时读取几个字节 |
| `NULL` | 空指针，指向地址 0，不可解引用 |

## 3. 指针与数组

数组名在多数场景下会退化为指向首元素的指针。

## 4. 常见错误

- 使用未初始化的指针
- 解引用已释放的内存（野指针）
- 数组越界访问
